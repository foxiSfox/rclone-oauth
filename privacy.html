Personal Drive Backup

Privacy Policy

Last updated: November 1, 2026

Personal Drive Backup is a personal integration powered by rclone for backing up the owner's files to their Google Drive. The owner is the application's only user. This policy describes how this integration handles data and how its informational website operates.

1. Data processed

To perform backup tasks, rclone processes:

  • the contents of files that the owner copies, verifies, or restores;
  • file and folder metadata, including names, identifiers, sizes, modification dates, and other information needed for the selected operations;
  • OAuth tokens issued by Google to access the account within the permissions granted.

The exact scope of accessible data depends on the Google OAuth permissions granted. Access may extend beyond the folder selected for backups. The application does not request or store the Google Account password.

2. How data is used

Data is used exclusively for personal backup operations: uploading, verifying, updating, and restoring backups, as well as deleting files and folders when the owner explicitly selects the corresponding rclone commands or settings.

This integration does not use data for advertising, profiling, sale, or training artificial intelligence models.

3. Storage and retention

Backups are stored in the owner's Google Drive. Original and restored files remain on the devices or server selected by the owner. The rclone configuration and saved OAuth tokens are stored in the environment where the owner has configured rclone.

Depending on its settings, rclone may create local logs or temporary files. Logs may contain file names and paths, operation details, and error information.

The owner determines how long backups, configuration, and logs are kept. Backups are deleted manually by the owner or through tasks they have configured. The timing of permanent deletion in Google Drive also depends on its trash functionality and Google's policies.

4. Data sharing

To perform backups, files and necessary technical data are transferred between the owner's environment running rclone and Google Drive. Google's processing of data is governed by the Google Privacy Policy.

This personal integration does not sell data or share it with advertising or analytics services. Publishing this website on GitHub Pages does not publish backups or send Google Drive contents or OAuth tokens to GitHub.

5. Revoking access and deleting data

The owner can stop rclone tasks at any time and revoke Personal Drive Backup's access in the third-party connections section of their Google Account.

Revoking access does not, by itself, delete existing backups, local files, or the rclone configuration. To delete data, separately remove the relevant backups from Google Drive, empty the trash if needed, and delete local tokens, configuration, and logs.

6. Informational website

This website consists only of static pages. It has no file upload forms, sign-in functionality, advertising scripts, or analytics services added by the owner. The page code does not set cookies or use browser local storage.

When the website is hosted on GitHub Pages, GitHub may process technical information about visits, including IP addresses, under the GitHub Privacy Statement.

7. Contact and policy updates

The application is maintained by its owner. For contact, use the support email address shown on the Google OAuth consent screen for Personal Drive Backup.

The owner updates this page when the application's purpose or data handling practices change. The date of the current version appears at the beginning of this document.
